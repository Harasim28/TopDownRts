# TopDownRts — доменная модель v2

Учебный каркас RTS на C#/.NET 10 по Event Storming-доске «Космические корабли». Версия v2 делает домен объектной моделью: сущности защищают свои инварианты, сервисы оркестрируют операции.

## Запуск

```bash
export DOTNET_ROOT=$HOME/.dotnet; export PATH=$HOME/.dotnet:$PATH
dotnet test
dotnet build
```

Тесты — поведенческая документация. Auth (2FA) сохранён без изменений.

## Что изменилось в v2

1. **Абстракция:** `ShipUnit`, `Fleet`, `Lobby` и `PlayerRating` выражают игровые понятия, а не наборы полей.
2. **Инкапсуляция:** живучесть корабля и состав флота меняются только командами сущностей; наружу отдаются только чтения.
3. **Модульность:** монолит `Interfaces.cs` разнесён по контрактам боя, лобби, флотов, рейтинга и конфигурации.
4. **Контракты:** конструкторы и `BalanceConfig` валидируют аргументы; конфигурация не имеет публичных setter/init-мутаторов.
5. **Композиция:** `Fleet` содержит корабли; `Battle` содержит флоты; наследование для отношений «является» не используется.
6. **Единое правило урона:** расчёт залпа и применение урона принадлежат сущностям флота/корабля, сервис не дублирует формулу.
7. **Ответственности:** сервисы координируют тик, очередь и репозиторий; доменные правила живут рядом с данными.
8. **TDD-покрытие:** сохранены прежние сценарии и добавлены проверки конфигурации, границы живучести и запрет ничьей.

## Соответствие Event Storming-доске

| Кадр | Команды/события | Реализация v2 | Статус |
| --- | --- | --- | --- |
| Вход и профиль | Login+2FA, PlayerAuthenticated | `Rts.Auth` | ✅ |
| Сбор матча | QueueJoined, MatchFound, ReadyUp, ReadyTimeout | `LobbyService` + `Lobby` | ✅ |
| Выбор флота | FleetUpdated, ConfirmFleet | `FleetRegistry` + `Fleet` | ✅ ядро |
| Бой по тикам | DamageApplied, ShieldAbsorbed, ShipDestroyed, FleetWipedOut, BattleEnded | `CombatService`, `Fleet`, `ShipUnit` | ✅ ядро |
| Итоги | UpdateRating, StatsRecorded | `RatingRepository`, `PlayerRating` | ✅ упрощённый ±N |
| UI/комнаты, движение, метеориты, дистанция, дуэли, concede | отложенные правила доски | не добавлялись | ⛔ вне текущего объёма |

Осознанные границы не изменены: подбор — первая пара, попадание гарантировано, рейтинг простой ±N, без новых фич.

## Принципы Буча в реализации

- **Абстракция:** доменные объекты имеют осмысленное поведение (`ReceiveDamage`, `FireAt`, `Ready`, `Win`, `Lose`).
- **Инкапсуляция:** состояние кораблей, флотов, лобби и рейтинга защищено; команды проверяют аргументы и инварианты.
- **Модульность:** контракты разделены по тематическим файлам, Auth не связан с доменной переделкой.
- **Иерархия:** «является» не подменяется наследованием ради переиспользования; игровые части представлены композицией.
- **Контракты:** сервисы зависят от интерфейсов, конфигурация неизменяема после создания.
