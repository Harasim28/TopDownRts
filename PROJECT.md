# PROJECT: TopDownRts (ООАиП)

## Цель
Учебный каркас RTS (курс ООАиП): по Event Storming-доске «Космические корабли» построена объектная модель. Показывает принципы Буча: богатый домен, инварианты в сущностях, сервисы-оркестраторы.

## Архитектура
- .NET 10, C#; `src/Rts.Domain` — домен (ShipUnit/Fleet/Lobby/PlayerRating, контракты в отдельных файлах), `src/Rts.Auth` — 2FA.
- `tests/` — xUnit, 27 тестов (19 доменных + 8 Auth) — поведенческая документация.
- Подробная карта файлов — README.md.

## Запуск
```bash
dotnet test   # 27/27 зелёные — обязательное условие любого коммита
dotnet build
```
